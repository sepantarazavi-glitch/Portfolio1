# Personal Portfolio Website – Front-End Practice

A simple single-page portfolio website created as a **practice project** to strengthen my front-end development skills and experiment with HTML, CSS, and JavaScript.

This project was built for learning and testing purposes. It is not intended to represent a finished professional portfolio. The main goal was to practice building a complete web page, organizing sections, styling a user interface, and adding basic JavaScript interactions.

## Overview

The website presents a simple personal profile with sections for:

- About Me
- Technical Skills
- Projects
- Recommendations
- Contact / Recommendation Form

It also includes a small interactive feature that allows a user to add a recommendation to the page and displays a confirmation popup.

## Technologies

- HTML5
- CSS3
- JavaScript
- SVG

## Main Features

- Single-page portfolio layout
- Navigation links between sections
- Personal introduction section

- Recommendation section
- Interactive recommendation form
- JavaScript popup confirmation

## How to Run

No installation or external dependencies are required.

1. Clone or download the repository.
2. Open the `singlepagewebsite` folder.
3. Open `index.html` in a web browser.

## JavaScript Interaction

The recommendation form uses JavaScript to:

1. Check whether the message field contains text.
2. Display a confirmation popup.
3. Add the new recommendation to the page.
4. Clear the input field.

The recommendations are only stored in the current page session. There is no database or backend connected to the form.
